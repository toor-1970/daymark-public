Daymark

Support

Daymark is a private mood log on this iPhone. The passphrase stays on the phone.

Choose a passphrase

Open Daymark. The first screen says "Choose a passphrase."

Use at least 8 characters. Type the same words again under Confirm. The switch "Stay unlocked on this phone" starts on. Leave it on if you want Face ID to open the log next time. Turn it off if you want to type the passphrase whenever the log is locked. The phone may ask for Face ID when the switch is on. The passphrase is never stored.

Tap Lock the log. That seals the log on this phone. It is checked only here, and it is never sent.

It cannot be reset

The passphrase cannot be reset. There is no account and no recovery. If you forget it, the log stays closed. Daymark cannot open it for you.

Lock

When the log is open, tap Lock at the top. The log closes. The encrypted copy stays on the phone.

To open it again, type the same passphrase and tap Unlock. If "Stay unlocked on this phone" was on, Face ID can open it until you tap Lock. After Lock, the passphrase is required again.
